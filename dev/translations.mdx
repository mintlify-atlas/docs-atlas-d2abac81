---
title: "Translations"
description: "How to contribute translations to Bitcoin Wallet using Transifex and the tx command-line client."
---

Bitcoin Wallet is translated by the community via [Transifex](https://explore.transifex.com/bitcoin-wallet/bitcoin-wallet/). The source language is **English**. German translations are maintained directly in the repository; all other languages go through Transifex.

The Transifex project manages two Android string resource files and two plain-text store-listing files:

| Resource | Source file |
|---|---|
| App strings | `wallet/res/values/strings.xml` |
| Help strings | `wallet/res/values/strings_help.xml` |
| Short description (store listing) | `metadata/en-US/short_description.txt` |
| Full description (store listing) | `metadata/en-US/full_description.txt` |

## Setting up the Transifex client

Install the `tx` command-line client once on your development machine:

```bash
sudo apt install transifex-client
```

## Pushing source strings (maintainer only)

When you add or change strings in the English source files, push them to Transifex so translators can see the new content. You need project maintainer access to do this.

```bash
tx push -s
```

## Pulling a translation

Once a translation is complete on Transifex, pull it into the repository:

```bash
tx pull -f -l <language-code>
```

Replace `<language-code>` with the appropriate Transifex language code, for example `fr` for French or `ja` for Japanese.

<Note>
  Always manually review pulled translations before committing them. Both translators and the Transifex platform occasionally introduce formatting bugs (e.g., mismatched placeholders, broken XML tags, or inconsistent punctuation) that must be corrected by hand.
</Note>

## Workflow summary

<Steps>
  <Step title="Update English source strings">
    Edit `wallet/res/values/strings.xml` or `wallet/res/values/strings_help.xml` with the new or changed strings.
  </Step>
  <Step title="Push to Transifex">
    Run `tx push -s` to upload the updated source strings. This step requires maintainer access.
  </Step>
  <Step title="Wait for translations">
    Translators on Transifex translate the new strings into their respective languages.
  </Step>
  <Step title="Pull translations">
    Run `tx pull -f -l <language-code>` for each language that is ready. Alternatively, pull all languages at once with `tx pull -f`.
  </Step>
  <Step title="Review and fix">
    Open each pulled file and check for formatting issues. Correct any bugs introduced during translation or by the Transifex platform.
  </Step>
  <Step title="Commit">
    Commit the updated translation files to the repository.
  </Step>
</Steps>

## Per-app language preferences (Android 13+)

On Android 13 and later, users can select a different language for Bitcoin Wallet independently of the system language. This uses the standard Android per-app language preference API and requires no special configuration in the app.

<Tip>
  If you speak a language that is not yet translated, visit [Transifex](https://explore.transifex.com/bitcoin-wallet/bitcoin-wallet/) to request access and start contributing.
</Tip>
